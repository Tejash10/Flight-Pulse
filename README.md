# ✈️ Flight Pulse – Flight Data Analysis

## 📌 About the Project

Flight Pulse is a data analytics project focused on analyzing airline performance, flight delays, and flight trends. The project uses data analytics tools and visualization techniques to transform flight data into meaningful insights.

The main objective is to understand airline performance, identify flight delays, analyze trends, and present insights through interactive dashboards.

## 🎯 Project Objectives

- Analyze airline performance.
- Identify flight delays and their patterns.
- Explore flight data and trends.
- Clean and process datasets.
- Create interactive dashboards.
- Generate meaningful business insights.

## 🛠️ Technologies Used

- **Python** – Data analysis and data processing.
- **SQL** – Data querying and analysis.
- **Power BI** – Interactive dashboards and visualization.
- **Excel** – Data handling and analysis.
- **Data Analytics** – Data cleaning, exploration, and reporting.

## 📊 Project Features

- Airline Performance Analysis
- Flight Delay Analysis
- Flight Data Visualization
- Interactive Power BI Dashboards
- Data Cleaning and Processing
- Flight Trend Analysis
- Dashboard-based Insights
