# ✈️ Flight Pulse – Flight Data Analysis

Flight Pulse is a data analytics project focused on analyzing airline performance, flight delays, and flight trends using data analytics tools.

## 🛠️ Technologies Used
- Python
- SQL
- Power BI
- Excel
- Data Analysis and Visualization

## 📊 Project Features
- Airline Performance Analysis
- Flight Delay Analysis
- Flight Data Visualization
- Interactive Power BI Dashboards
- Data Cleaning and Processing

## 📁 Project Structure
- `api/` – API-related files
- `chatbot/` – Chatbot files
- `Data/` – Project datasets
- `power bi/` – Power BI dashboards
- `Python/` – Python analysis
- `Screenshot/` – Dashboard screenshots
- `Sql/` – SQL queries
